🎵 Spotify Clone — React + Tailwind CSS

A modern and responsive Spotify-inspired music streaming frontend built using React.js and Tailwind CSS.

The project focuses on recreating the Spotify user interface with reusable React components, responsive layouts, music browsing, playlists, albums, and a functional-looking music player interface.

🚧 This project is a frontend UI clone created for learning and practice purposes. It is not affiliated with or endorsed by Spotify.

🚀 Getting Started

1. Clone the repository

git clone https://github.com/your-username/spotify-clone.git

2. Navigate to the project

cd spotify-clone

3. Install dependencies

npm install

4. Start the development server

npm run dev

The application will be available at:

http://localhost:5173
